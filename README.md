# Build and test a multi-tier application with GitHub Copilot

## Welcome

Build the OctoFit Tracker across the presentation, logic, and data tiers using GitHub Copilot.

![OctoFit Tracker](.github/images/octofit-tracker.png)

Work through the numbered steps in order, then open a pull request with your implementation. The API uses port `8000`, the frontend uses port `5173`, and MongoDB uses port `27017`.

[![](https://img.shields.io/badge/Go%20to%20Exercise-%E2%86%92-1f883d?style=for-the-badge&logo=github&labelColor=197935&template_owner=skills&template_name=build-applications-w-copilot-agent-mode)](https://github.com/AhmedSenosy0122/skills-build-applications-w-copilot-agent-mode/issues/1)

## Having trouble? 🤷

Review the troubleshooting notes in the current step, check the documented test commands in `docs/architecture.md`, and inspect the failing contract test before changing implementation code.
